      Instalar no computador

      A Área de Trabalho pode ser instalada como app no Windows e no Linux, com ícone próprio e janela separada.

      1. Abra este endereço no Google Chrome, Microsoft Edge, Brave ou Chromium:
        https://eguilherme88-wq.github.io/area-de-trabalho/
      2. Clique no ícone de instalar na barra de endereço (um monitor com seta) ou no menu ⋮ → Transmitir, salvar e compartilhar → Instalar página como app.
      3. Confirme em Instalar. O atalho aparece no Menu Iniciar (Windows) ou no menu de aplicativos (Linux).

      O Firefox não instala apps web. Use um dos navegadores acima. Para desinstalar, abra o app e use o menu ⋮ → Desinstalar.
